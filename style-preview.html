Vitals // STYLE PREVIEW

静态预览板，不连后端。当前提供 9 套风格，每套 8 支强调色。

01 · 界面风格对照

Default：初版那套。纯黑底、直角、灰阶、等宽字，硬核仪表盘的路子。
Modern：苹果那一挂。近白的冷灰底 + 白色玻璃卡片，圆角开到 20px， 层次全靠留白和一层毛玻璃撑起来。没有花纹、没有描边线、没有渐变块。
Frutiger Aero：清透的蓝天、草地、水珠和玻璃气泡。2004-2013 那一波"自然 + 科技 + 乐观"。 底色是干净的天空蓝 → 水青，右上角一团阳光；质感靠水润的玻璃高光和拟物反光，不是塑料的。
Rococo：18 世纪法国装饰艺术。奶油粉底色配玫瑰、薰衣草、薄荷的光晕，面板像上釉的瓷器， 圆角开到最大、边缘用柔化的玫瑰唇线——洛可可的规矩是不许出现锐利的东西，也不许出现重颜色。
Soviet：苏联构成主义。1920 年代苏联先锋派那一路（罗德琴科、塔特林、李西茨基）。 红 + 黑 + 米白，一道巨大的红色斜切色块，硬边矩形、粗重的无衬线字、硬投影。 要的是平面上的"力量感"——没有渐变、没有圆角、没有一丝柔软的东西。
Ink：国风。生宣那种带灰黄的暖白打底，墨色是掺了青的松烟墨，只在品牌标记和告警上点一枚朱砂。 圆角收到近乎直角、线条细到刚好看得见、标题不用粗体压——留白比装饰重要。
Cyberpunk：深蓝紫的夜 + 七团霓虹光雾（品红/青/紫/黄/绿/橙/蓝）。发光边框、霓虹灯管标题、 锋利直角，背景换成远近两层城市天际线剪影 + 一道地平线辉光。参照 synthwave 和赛博朋克 2077。
NASA：近黑的深空 + 极暗的星云余晖 + 拉丝金属面板 + 橙红识别条。 星点压得很低，面板是暗色金属板，顶上那道橙条是唯一的一抹暖色——深沉，不抢戏。
Hacker：千禧年前后互联网对黑客的想象——夜视绿 CRT 终端、母体代码雨、扫描线。 主色只有一味荧光绿，其余全是黑。背景那层乱码雨是真在滚的字符（片假名 + 数字）， 由一块全屏画布持续下淌，不是贴静态图。
质感不是靠换色堆出来的：每套主题覆写的是同一组变量（圆角、高光层、浮雕、投影、进度条渐变）， 组件本身一行没改。小游戏的棋盘（贪吃蛇 / 五子棋）、蛇身和棋子也是从这组变量里取色， 换主题自动跟着走。温度曲线和首页卡片同理。

02 · 强调色

强调色跟着风格走，每套各有一张表。浅底上放荧光绿会糊，深底上放深蓝会看不见， 所以不能共用一份色表。
